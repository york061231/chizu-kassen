プライバシーポリシー

対象：YouTube チャンネル「地図で読む 世界の合戦」の投稿ツール（以下「本ツール」）。施行日：2026 年 11 月 18 日（11 月 17 日版にサムネイルと再生リストを書き足した）。利用規約はこちら。

1. 本ツールについて

本ツールは、チャンネルの運営者 1 人だけが、自分で作った動画を自分のチャンネルへ投稿し、サムネイルを付け、運営者の再生リスト（縦・長尺）を作って動画を足し、その状態（処理の状況・公開の状態・公開予約の日時）を確かめるために使うプログラムです。運営者以外の人は使いません。本ツールは YouTube API サービスを使っています。

本ツールを使うことは、YouTube 利用規約に同意することになります。Google によるデータの扱いは Google プライバシー ポリシーをご覧ください。

2. 扱う情報

  • 許可の情報（OAuth のトークン）：運営者が Google アカウントで許可したときに発行されるもの。運営者の PC の中だけに保存し、投稿と状態の確認にだけ使います。
  • 運営者の動画の情報：本ツールで投稿した動画の ID・処理の状況・公開の状態・公開予約の日時。運営者の PC の台帳に保存し、毎日の確認で新しい情報に書き換えます（30 日を超えて古いままにしません）。
  • 運営者の再生リストの ID と名前：本ツールが作った 2 つの再生リスト。運営者の PC の設定ファイルに保存し、動画をリストへ足すときにだけ使います。
  • 視聴者・コメント・他のチャンネルの情報は取得しません。
  • ウェブサイト（このページを含む）は Cookie・アクセス解析・広告を使いません。本ツールは広告を配信しません。

3. 使い道と共有

上の情報は、動画の投稿・サムネイルの設定・再生リストへの追加・公開予約・状態の確認と、運営者自身への通知にだけ使います。通知（動画の ID と状態の 1 行）は、運営者が自分用に作った Discord のチャンネルへ送ります。それ以外の第三者には渡しません。販売もしません。

4. 許可の取り消しと削除

本ツールへの許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。取り消した場合や削除の依頼があった場合、本ツールが保存した情報は 7 日以内に削除します。

5. 問い合わせ

Privacy Policy

Applies to: the upload tool of the YouTube channel “地図で読む 世界の合戦” (Reading the World’s Battles on Maps) — the “Tool”. Effective date: November 18, 2026 (the November 17 version with thumbnails and playlists added). See also the Terms of Service.

1. About the Tool

The Tool is a program used only by the channel’s single operator to upload the operator’s own videos to the operator’s own YouTube channel, set their thumbnails, create the operator’s playlists (vertical / long) and add the videos to them, and check their state (processing status, privacy status, scheduled publish time). No one else uses it. The Tool uses YouTube API Services.

By using the Tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

2. Information the Tool uses

  • Authorization data (OAuth tokens) issued when the operator authorizes the Tool with their Google account. Stored only on the operator’s computer and used only to upload videos and read their state.
  • Data about the operator’s own videos: video IDs, processing status, privacy status and scheduled publish time of videos uploaded with the Tool. Stored in a ledger file on the operator’s computer and refreshed by a daily check (never kept stale for more than 30 days).
  • IDs and names of the operator’s playlists: the two playlists the Tool created. Stored in a settings file on the operator’s computer and used only to add videos to them.
  • The Tool does not collect data about viewers, comments or other channels.
  • The website (including this page) uses no cookies, analytics or ads. The Tool does not serve ads.

3. Use and sharing

This information is used only to upload and schedule videos, set their thumbnails, add them to playlists, check their state, and notify the operator. Notifications (one line with a video ID and its state) are sent to a Discord channel the operator created for themselves. Nothing is shared with any other third party or sold.

4. Revoking access and deletion

You can revoke the Tool’s access at any time on the Google security settings page. After access is revoked, or on request, data stored by the Tool is deleted within 7 days.
