1. About the Tool

The Tool is a program used only by the channel’s single operator to manage the operator’s own videos on the operator’s own channel. It:

  • uploads the operator’s videos to the operator’s channel (as private uploads with a scheduled publish time),
  • sets the title, description, tags, category and scheduled publish time of the operator’s own videos that the operator uploaded in YouTube Studio,
  • sets a custom thumbnail on each uploaded video,
  • creates the operator’s playlists (vertical videos / long videos) and adds each video to the matching one if it is not there yet,
  • checks the state of the uploaded videos (processing status, privacy status, scheduled publish time).
